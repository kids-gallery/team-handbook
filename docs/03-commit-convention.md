# 커밋 컨벤션

## 커밋 메시지 형식
type: description (#issue)

## 타입
- feat: 기능 추가
- fix: 버그 수정
- docs: 문서 작성 및 수정
- refactor: 코드 구조 개선
- test: 테스트 추가 및 수정
- chore: 설정 및 유지보수

## 예시
docs: add introduction (#1)
docs: add commit convention (#3)
fix: correct documentation typo (#3)

## 작성 규칙
1. 커밋 메시지는 변경 목적을 명확하게 작성합니다.
2. 하나의 커밋에는 하나의 목적을 담습니다.
3. 관련 Issue 번호를 포함합니다.
4. 불필요한 파일은 커밋하지 않습니다.
