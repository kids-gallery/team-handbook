# Team Handbook

## 프로젝트 소개
Git과 GitHub를 이용한 팀 협업 실습 저장소입니다.

## 프로젝트 목표
- Issue 기반 작업 관리
- 기능 브랜치 활용
- Pull Request 리뷰
- Merge 충돌 해결
- Git 사고 복구 및 원인 추적

## 팀원 역할
- A(wpalswpa): 저장소 초기 설정, 프로젝트 소개, 커밋 컨벤션, B의 PR 리뷰
- B(zozu001): 브랜치 전략, FAQ, A의 PR 리뷰
- C(tlswlgus960-prog): 조직 Owner 초대 수락 후 팀장 역할
- 초대 대기는 실제 권한 획득과 다릅니다. B와 C는 초대를 수락한 뒤 역할을 수행합니다.

## 협업 규칙
1. 모든 작업은 Issue 생성 후 시작합니다.
2. 초기 설정 이후 main에 직접 Push하지 않습니다.
3. 작업 브랜치에서 커밋합니다.
4. PR을 생성하고 상대 팀원의 리뷰를 받습니다.
5. 승인 후 main에 병합합니다.
6. 브랜치 보호가 플랜 제한으로 적용되지 않으면 승인 확인을 팀원이 직접 지킵니다.
