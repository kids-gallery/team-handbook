# Team Handbook

## 프로젝트 소개
Git과 GitHub를 이용한 팀 협업 실습 저장소입니다.

## 프로젝트 목표
- Issue 기반 작업 관리
- 기능 브랜치 활용
- Pull Request 리뷰
- Merge 충돌 해결
- Git 사고 복구 및 원인 추적

## 팀원 역할
- A(wpalswpa): 저장소 초기 설정, 프로젝트 소개, 커밋 컨벤션, B의 PR 리뷰, 충돌 실습(A쪽), 잘못된 커밋 복구 실습
- B(zozu001): 브랜치 전략, FAQ, A의 PR 리뷰, 충돌 해결, 원인 커밋 추적(bisect)
- C(tlswlgus960-prog): 팀장(조직 Owner, 저장소 관리자), 모든 PR의 두 번째 리뷰와 병합, 원인 추적 실습용 커밋 이력 준비

## 협업 규칙
1. 모든 작업은 Issue 생성 후 시작합니다.
2. 초기 설정 이후 main에 직접 Push하지 않습니다.
3. 작업 브랜치에서 커밋합니다.
4. PR을 생성하고 작성자가 아닌 팀원의 리뷰를 받습니다.
5. 승인 후 main에 병합합니다.
6. main은 PR 승인 1회를 요구하며 관리자에게도 보호 규칙을 적용합니다.
